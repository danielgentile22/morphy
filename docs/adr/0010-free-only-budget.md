# ADR-010: Strict free-only data budget

**Status:** Revised by [ADR-057](0057-budget-posture-reframed.md) — reframed from "permanent stance" to "current budget posture for Phase 1." Paid unlocks expected Phase 2+.
**Date:** 2026-05-19

## Context

User confirmed budget posture is "strict free only" for the pitch cut.

## Decision

No paid data (Regrid, ATTOM, CoreLogic, …) and no paid SaaS until / unless explicitly unlocked. Stubs stay in code but are documented as out of scope.

## Consequences

Statewide parcel coverage is patchwork — limited to the ~7 free statewide feeds. Anchor states chosen accordingly.

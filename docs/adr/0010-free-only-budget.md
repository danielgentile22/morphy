# ADR-010: Strict free-only data budget

**Status:** Revised by [ADR-057](0057-budget-posture-reframed.md), which reframed it from a "permanent stance" to "the budget posture for Phase 1." Paid data was left for a later phase that never started.
**Date:** 2026-05-19

## Context

The user set the budget posture to "strict free only" for the first cut.

## Decision

No paid data (Regrid, ATTOM, CoreLogic, …) and no paid SaaS until / unless explicitly unlocked. Stubs stay in code but are documented as out of scope.

## Consequences

Statewide parcel coverage is patchwork, limited to the ~7 free statewide feeds. Anchor states chosen accordingly.

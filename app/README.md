# Morphy map app (`app/`)

Catalog-driven multi-state parcel and infrastructure map. It renders the
AR, MT, FL and WV composites, and any newly composed state appears without
code changes.

Stack: **Svelte 5 + Vite + TypeScript**, **MapLibre GL** (rendering),
PMTiles (parcel tiles), DuckDB-WASM (in-browser filter and search). The app
uses both PMTiles and DuckDB-WASM at runtime.

## Prerequisites

- Node.js ≥ 20, npm
- The AR/MT/FL/WV composites on disk under `data/processed/composite/`
- `composite/index.json`, generated by:
  ```bash
  source ../.venv/bin/activate
  python ../scripts/preprocess.py --app-assets
  ```

## Basemap key (optional)

The default basemap is MapTiler Satellite Hybrid, which needs a client-side
key. Copy `app/.env.example` to `app/.env` (git-ignored) and set
`VITE_MAPTILER_KEY`. Vite reads `app/.env` in dev and at build time.

Without a key the app still works. `src/lib/basemap.ts` hides the Satellite
option in settings and maps any stored `satellite` preference to the keyless
Carto Dark Matter basemap, so the map never requests MapTiler tiles it would
be refused. The Carto Positron, Voyager and Dark Matter basemaps never need a
key.

For the Docker build, `deploy.sh` reads `VITE_MAPTILER_KEY` from the
environment or the repo-root `.env` and passes it as a build arg. An empty
value builds the keyless fallback.

## Develop

The app fetches data with root-relative `/data/...` paths. In dev, Vite
serves the app and proxies `/data` to a static server at the repo root, so
**two servers** must run:

```bash
# terminal 1: static data server at the repo ROOT (not app/)
cd ..
python scripts/serve.py 8765

# terminal 2: Vite dev server (proxies /data -> :8765)
cd app
npm install
npm run dev            # http://localhost:5173
```

Vite also proxies `/api` to the backend on `:8000`. The app shows only a
sign-in gate until the backend confirms a session, so run the backend too
(see [`../backend/CLAUDE.md`](../backend/CLAUDE.md)).

## Build

```bash
npm run build          # type-checks, then builds to dist/
npm run preview        # serve the built dist/ locally
```

`dist/` is git-ignored. For a demo, serve the built app and `data/` from
one origin (one static server at the repo root).

## Test

```bash
npm run test:unit      # Vitest: unit + integration
npm run test:e2e       # Playwright: E2E (starts both servers itself)
npm test               # both
```

Playwright browsers install once: `npx playwright install chromium webkit`.

# Pilot Map App (`app2/`)

Catalog-driven multi-state parcel & infrastructure map. Renders the
AR + MT composites today; any future composed state appears automatically.

Stack: **Svelte 5 + Vite + TypeScript**, **MapLibre GL** (rendering),
PMTiles (parcel tiles — Phase B), DuckDB-WASM (filter/search — Phase C).

> Built under `app2/` during the rehaul; it replaces `app/` at the
> Phase D cutover. See `_review/APP_REHAUL_PLAN.md`.

## Prerequisites

- Node.js ≥ 20, npm
- The AR/MT composites on disk under `data/processed/composite/`
- `composite/index.json` — generated by:
  ```bash
  source ../.venv/bin/activate
  python ../scripts/preprocess.py --app-assets
  ```

## Develop

The app fetches data with root-relative `/data/...` paths. In dev, Vite
serves the app and proxies `/data` to a static server at the repo root —
so **two servers** must run:

```bash
# terminal 1 — static data server at the repo ROOT (not app2/):
cd ..
python scripts/serve.py 8765

# terminal 2 — Vite dev server (proxies /data -> :8765):
cd app2
npm install
npm run dev            # http://localhost:5173
```

## Build

```bash
npm run build          # type-checks, then builds to dist/
npm run preview        # preview the production build
```

`dist/` is git-ignored. For a demo, serve the built app and `data/` from
one origin (one static server at the repo root).

## Test

```bash
npm run test:unit      # Vitest — unit + integration
npm run test:e2e       # Playwright — E2E (starts both servers itself)
npm test               # both
```

Playwright browsers install once: `npx playwright install chromium webkit`.
